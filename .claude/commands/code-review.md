作業中のブランチの実装コードを、仕様書・コーディング規約の観点でレビューしてください。

## 手順

**1. 変更ファイルの確認**
- `git diff develop...HEAD --name-only` で変更ファイルを一覧する
- ソースファイル（`src/`）とテストファイル（`*.test.ts`）を確認する

**2. 参照資料の読み込み**
- `docs/05_develop/implementation-rules.md` のコーディング規約を確認する
- 関連する `specs/{機能名}.md` の機能要件・受け入れ条件を確認する

**3. レビュー観点**

| 観点 | チェック内容 |
|---|---|
| コーディング規約 | `implementation-rules.md` に違反している箇所がないか |
| 仕様準拠（実装） | 機能要件がすべて実装されているか |
| 仕様準拠（テスト） | 受け入れ条件に対応するテストが存在するか |
| 余分な実装 | 仕様に記載のない実装が混入していないか |

**4. 結果の報告**
- 指摘事項があればリストアップする
- 問題なければ「レビュー OK」と報告する
- 指摘があれば修正してからステップ 5（ブラウザ動作確認）へ進む
