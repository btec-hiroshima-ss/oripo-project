作業中のブランチの仕様書に記載された受け入れ条件に従い、ブラウザで動作確認してください。

## 前提

- アプリ URL: `http://host.docker.internal:3000`（chrome-devtools MCP を使用）
- ログイン情報: ユーザー名=`Rescho` / パスワード=`rescho`

## 手順

**1. 受け入れ条件の確認**
- `git diff develop...HEAD --name-only` で変更ファイルを確認する
- 関連する `specs/{機能名}.md` の `## 受け入れ条件` を読み込む

**2. ブラウザ操作**
- `navigate_page` でアプリにアクセスし、ログインする
- 受け入れ条件を1つずつ操作して確認する
- 各条件の結果を OK / NG で記録する

**3. レスポンシブ確認**
- `resize_page` でモバイルサイズ（幅 375px）にリサイズして再確認する
- モバイル向けの受け入れ条件があればすべてチェックする

**4. 結果の報告**
- 全条件を OK / NG 付きでリストアップする
- NG があれば修正してから再確認する
- 仕様の解釈に疑問がある場合はユーザーに確認を求めてから進む
- 全条件 OK になったらステップ 6（push & PR 作成）へ進む
