## 1. 機能概要

AIPO へのアクセス時に最初に表示される認証画面。ユーザー名とパスワードで認証する。

## 2. 画面レイアウト

```
┌──────────────────────────────────┐
│          [Aipo7 ロゴ]            │
│                                  │
│  ┌──────────────────────────┐    │
│  │ エラーメッセージ（任意）  │    │
│  └──────────────────────────┘    │
│  [ユーザー名          ]          │
│  [パスワード          ]          │
│  ☑ ユーザー名を保存する          │
│                   [🔒 ログイン]  │
└──────────────────────────────────┘
```

## 3. 入力項目

| 項目 | 内容 |
|---|---|
| ユーザー名 | ログインID（文字列） |
| パスワード | 大文字・小文字を区別 |
| ユーザー名を保存する | チェックで次回ユーザー名を自動入力 |

## 4. 認証仕様

- パスワードは SHA-1 + Base64 でハッシュ化して DB（`turbine_user.password_value`）に保存
- 認証失敗時は「ユーザー名とパスワードを正しく入力してください。大文字と小文字を区別する必要があります。」を表示

## 5. 特記事項・制約

- セッション管理は Apache Shiro（1.0.0-incubating）が担当
- ログアウトはグローバルナビゲーションから行う
