# 更新情報 仕様（現AIPO）

調査日：2026-05-26
調査元：https://github.com/arkjun/aipo（portlets/whatsnew）

---

## 1. 機能概要

スケジュール・掲示板・ブログ・共有Todo・共有フォルダなど、各機能の更新履歴を自動集約して一覧表示する読み取り専用のフィード。誰がいつ何を追加・編集したかを時系列で確認できる。投稿・返信などの操作はできない。

## 2. 主要な操作・画面

- 更新情報の一覧表示（全アプリ or アプリ別フィルタ）
- キーワード検索
- 各更新内容のリンクをクリックして該当機能へ遷移
- ページング

## 3. データ項目

| 項目名 | 説明 |
|---|---|
| 内容 | 更新内容のテキスト（例：「予定『○○』を追加しました」） |
| 名前 | 更新者の氏名 |
| 更新日時 | 更新日・時刻 |

### アプリフィルタ（左サイドバー）

| フィルタ名 |
|---|
| すべてのアプリ |
| スケジュール |
| 掲示板 |
| ブログ |
| 共有Todo |
| 共有フォルダ |
| Aipoアプリ |


- 更新内容はリンクになっており、クリックで該当機能へ遷移
- ページング（20件/ページ）

## 5. 特記事項・制約

- 投稿・編集・削除などの操作は不可（閲覧専用）
- 各機能の更新が自動的に反映される（手動投稿なし）
- ACL対象外（全ユーザーが閲覧可能）
