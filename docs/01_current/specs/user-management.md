# ユーザー情報管理 仕様（現AIPO）

調査日：2026-05-26
調査元：https://github.com/arkjun/aipo（portlets/account）

---

## 1. 機能概要

管理者がユーザーアカウントを作成・編集・削除する管理機能。ユーザーの基本情報・所属部署・役職の管理に加え、部署マスタ・役職マスタ・会社情報の管理も含む。

## 2. 主要な操作・画面

- ユーザー一覧表示
- ユーザー新規作成・編集・削除
- パスワード変更
- 顔写真のアップロード
- 部署マスタ管理（追加・編集・削除・並び順変更）
- 役職マスタ管理（追加・編集・削除）
- 会社情報管理
- ユーザーの並び順変更

## 5. 特記事項・制約

- 管理者権限を持つユーザーのみ操作可能
- ユーザー1人が複数部署に所属できる（EipMUserPosition）
- ログインIDは変更不可（システムID）
- パスワードはハッシュ化して保存
