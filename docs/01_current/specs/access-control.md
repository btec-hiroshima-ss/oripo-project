# アクセス権限管理 仕様（現AIPO）

調査日：2026-05-26
調査元：https://github.com/arkjun/aipo（portlets/accessctl）

---

## 1. 機能概要

機能ごとのアクセス権限をロール単位で管理する機能。ロールに対して各機能の操作権限（一覧・詳細・追加・更新・削除・エクスポート）を設定し、ユーザーをロールに割り当てることで権限を制御する。各ユーザーの最終ログイン日時も確認できる。

## 2. ロールの概念

「ロール」は管理者が自由に作成・命名する権限セットのこと。

```
ロール（例：「一般社員」「マネージャー」）
  └── 機能×操作の権限を設定
        例）スケジュール（他ユーザー）: 閲覧○ 追加× 削除×

ユーザー → ロールに割り当て → そのロールの権限が適用される
```

システムで固定されているのはロール名ではなく、**権限の種類**（一覧・詳細・追加・更新・削除・エクスポート）と**対象機能**（スケジュール・タイムライン等）。

## 3. 主要な操作・画面

- ロール一覧表示
- ロール新規作成・編集・削除
- ロールへの権限設定（機能×操作の組み合わせ）
- ユーザーへのロール割り当て
- ユーザーの最終ログイン日時確認

## 4. データ項目

### EipTAclRole（ロール）

| カラム | 説明 |
|---|---|
| ロールID | 主キー |
| ロール名 | 最大50文字 |
| メモ | |

### EipTAclMap（権限マッピング）

権限の種類（0=無効 / 1=有効）：

| 権限名 | 説明 |
|---|---|
| acl_list | 一覧表示 |
| acl_detail | 詳細表示 |
| acl_insert | 追加 |
| acl_update | 更新 |
| acl_delete | 削除 |
| acl_export | エクスポート |

### EipTAclPortletFeature（対象機能）

今回の調査対象5機能における権限設定の範囲：

| 機能 | 設定対象 | 設定できる権限 |
|---|---|---|
| スケジュール | 自分の予定 | 一覧・詳細・追加・更新・削除 |
| スケジュール | 他ユーザーの予定 | 一覧・詳細・追加・更新・削除 |
| スケジュール | 設備の予約 | 追加・更新のみ |
| ユーザー名簿 | - | 一覧・詳細のみ |
| タイムライン | - | ACL対象外（全ユーザー操作可能） |
| ユーザー情報管理 | - | ACL対象外（管理者専用機能） |
| アクセス権限管理 | - | ACL対象外（管理者専用機能） |

### EipTAclUserRoleMap（ユーザー×ロール）

ユーザーとロールの紐付け。

## 6. 特記事項・制約

- ロールベースアクセス制御（RBAC）方式
- 機能単位で細かく権限を設定可能
- 管理者ロールはシステムデフォルトで存在
- 最終ログイン日時はユーザー管理の補助情報として参照可能（Issue #28 要件）
