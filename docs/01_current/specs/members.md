# ユーザー名簿 仕様（現AIPO）

調査日：2026-05-26
調査元：https://github.com/arkjun/aipo（portlets/userlist）

---

## 1. 機能概要

社内ユーザーの連絡先・プロフィール一覧を閲覧する機能。部署・グループ・キーワードで絞り込みができ、個人の詳細情報を参照できる。閲覧専用（編集はユーザー情報管理機能で行う）。

## 2. 主要な操作・画面

- ユーザー一覧表示（部署・グループ・キーワードで絞り込み）
- ユーザー詳細表示

## 3. データ項目

### 一覧・詳細の表示項目

| 項目名 | 説明 |
|---|---|
| 氏名 | 姓・名 |
| ふりがな | 姓・名（かな） |
| メールアドレス | |
| 外線電話番号 | |
| 内線電話番号 | |
| 携帯電話番号 | |
| 携帯メールアドレス | |
| 顔写真 | |
| 部署 | 複数部署に所属可 |
| 役職 | |

### 絞り込みキー

| 項目 | 説明 |
|---|---|
| 部署（Post） | 所属部署で絞り込み |
| グループ | 所属グループで絞り込み |
| キーワード | 氏名・ふりがなで部分一致検索 |

## 4. 特記事項・制約

- ユーザーデータはTurbineUser（セキュリティ管理テーブル）と紐付き
- 閲覧のみ。編集はユーザー情報管理（portlets/account）で行う
- アクセス権限管理でこの機能の閲覧可否を制御可能
