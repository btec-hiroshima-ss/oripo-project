## 1. 機能概要

ログイン後に表示されるメイン画面。左カラムに更新情報ウィジェット、右メインエリアにスケジュールが表示される。上部グローバルナビゲーションからマイページ・個人設定・システム管理に切り替えられる。

## 2. 画面レイアウト

2カラム構成。各ウィジェットはユーザーがカスタマイズ可能。

```
┌─────────────────────────────────────────────────────────────┐
│ Aipo7          [お知らせ] [会社名 ユーザー名] [ログアウト]  │
│─────────────────────────────────────────────────────────────│
│ [マイページ] [個人設定] [システム管理] [+]                  │
│─────────────────────────────────────────────────────────────│
│ 左カラム             │ 右カラム                            │
│──────────────────────┼─────────────────────────────────────│
│ 更新情報             │ スケジュール（週表示・複数ユーザー列）│
│ （テキストリンク一覧）│                                     │
│                      │                                     │
│──────────────────────┤─────────────────────────────────────│
│ 伝言メモ             │ 掲示板                              │
│──────────────────────│  トピック一覧                       │
│ ワークフロー         │─────────────────────────────────────│
│──────────────────────│ 共有Todo                            │
│ 報告書               │─────────────────────────────────────│
│──────────────────────│ 共有フォルダ                        │
│ アドレス帳           │  ファイル一覧                       │
│  [検索ボックス][検索]│                                     │
│──────────────────────│                                     │
│ ユーザー名簿         │                                     │
│  [検索ボックス][検索]│                                     │
└──────────────────────┴─────────────────────────────────────┘
```

## 3. グローバルナビゲーション

| タブ | 内容 |
|---|---|
| マイページ | ホーム画面（更新情報＋スケジュール） |
| 個人設定 | ユーザー情報・Myグループ・ページ設定・携帯電話設定 |
| システム管理 | 管理者専用（ユーザー管理・部署管理・アクセス権限管理等） |
| ＋ | ポートレット（機能）の追加 |

## 4. 特記事項・制約

- マイページのレイアウト（左右カラムの構成）はユーザーがカスタマイズ可能
- システム管理タブは管理者権限を持つユーザーのみ表示される
