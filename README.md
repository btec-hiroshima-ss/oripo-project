# Oripoプロジェクト

## プロジェクト概要
### 問題点
・ユーザーが増えると重い
・アップデートを全くしていないのでセキュリティリスク有り
 
### PJ方針
Claudeを最大限活用。各種成果物及びローカルテストはすべてClaudeが作成・実行→人がレビューの流れで行う。

### 開発手法
仕様駆動開発（SDD: Spec-Driven Development）とする。  
リバースエンジニアリングで仕様書作成容易＆Claudeフル活用なため適切。  
そのため、仕様・設計書といったドキュメント作成が最優先。
