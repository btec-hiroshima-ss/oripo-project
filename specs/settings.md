# 個人設定メニュー

## 概要

個人設定画面（ユーザーが自分の使い方に合わせて画面をカスタマイズする機能。AIPO の「個人設定」に
相当）の左側に表示される選択メニュー。ユーザー情報・Myグループ・ページ設定の3項目を切り替える。

ヘッダーの「個人設定」タブを押すと、別ページに移動するのではなく画面の中身だけが切り替わる
（`layout.md` で「モーダル」と書かれているのはこの切り替えのことで、ポップアップは出ない）。

**本仕様書で扱うのは左側の選択メニュー（#142）だけ。** ユーザー情報・Myグループ・ページ設定
の中身は別 Issue で作るので、ここでは空の枠（プレースホルダー）として扱う。

## 機能要件

### 左の選択メニュー

個人設定画面の左側に固定表示される選択メニュー。3つの項目を持ち、選択中の項目に応じて右側の
コンテンツエリアの表示を切り替える。

| 項目 | アイコン | デフォルト選択 |
|---|---|---|
| ユーザー情報 | 人物アイコン | ○（個人設定を開いた直後はこれを表示） |
| Myグループ | 人物×2アイコン | - |
| ページ設定 | グリッドアイコン | - |

> AIPO には上記3項目に加えて「携帯電話設定」が独立項目として存在するが、Oripo では携帯電話番号
> （社内）を「ユーザー情報とパスワードを編集する」に統合するため独立項目を設けない（要件定義書
> 2.7・確定モックアップと整合）。

- メニュー上部に「個人設定」というグループ見出しを小さいグレー文字で表示する（モックアップ準拠）
- 選択中の項目はオレンジ背景・オレンジ左ボーダー・オレンジ文字（太字）でハイライトする
- 非選択の項目はグレー文字。ホバー時に薄いグレー背景を表示する
- 項目クリックでコンテンツエリアの表示のみ切り替える（URL 遷移なし、ページリロードなし）
- ヘッダーの「個人設定」タブを再度クリックしてマイページへ戻った後、再度「個人設定」タブを開くと
  選択状態はユーザー情報にリセットされる（`showSettings` が false になった時点で state を破棄するため）

### コンテンツエリア（プレースホルダー）

#143〜#145 が実装されるまでの間、選択中の項目に応じたプレースホルダーパネルを表示する
（アイコン + タイトルの見出しのみ。本文は空欄）。将来、各 Issue でこの本文を実データ表示・
編集 UI に置き換える。

### レスポンシブ対応

| ブレークポイント | 挙動 |
|---|---|
| デスクトップ（lg 以上） | 左メニュー（固定幅）+ コンテンツエリアを横並び表示（モックアップ準拠） |
| モバイル（lg 未満） | 左メニューをコンテンツ上部の横スクロール可能なピルボタン列として表示し、その下にコンテンツエリアを縦に表示する（モバイルモックアップ不在のため、既存のページタブと同様のピル UI に合わせた独自判断） |

## API

本 Issue（#142）では DB アクセスを伴わない（メニューの選択状態はクライアント側 state のみ）。
API は #143〜#145 でパネルごとに追加する。

---

## データモデル

本 Issue では新規テーブル・カラムは不要。選択状態は `SettingsView` の React state（`useState`）で
管理し、DB には保存しない。

## ファイル構成

```
src/app/(main)/_components/
  SettingsView.tsx       ← 個人設定画面全体（左メニュー + コンテンツエリアの状態管理）
  SettingsMenu.tsx        ← 左の選択メニュー（デスクトップ: 縦並び / モバイル: 横スクロールピル）
  settings-panels/
    UserInfoPanel.tsx     ← ユーザー情報パネル（プレースホルダー、#143 で実装）
    MyGroupPanel.tsx       ← Myグループパネル（プレースホルダー、#144 で実装）
    PageSettingsPanel.tsx  ← ページ設定パネル（プレースホルダー、#145 で実装）
```

- [ ] 左メニューに「ユーザー情報」「Myグループ」「ページ設定」の3項目が表示される
- [ ] 選択中の項目はオレンジ背景・オレンジ左ボーダーでハイライトされる
- [ ] 「Myグループ」をクリックするとコンテンツエリアが Myグループパネルに切り替わる
- [ ] 「ページ設定」をクリックするとコンテンツエリアがページ設定パネルに切り替わる
- [ ] 各パネルにアイコン + タイトルの見出しが表示される
- [ ] ヘッダーの「個人設定」タブを閉じてマイページへ戻り、再度開くとユーザー情報が選択された状態に戻る

- [ ] モバイルでメニュー項目をタップするとコンテンツエリアが切り替わる
