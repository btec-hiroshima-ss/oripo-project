# 個人設定画面

## 概要

ユーザーが自身の環境をカスタマイズする画面。AIPO の「個人設定」ポートレットに相当する。
ヘッダーの「個人設定」タブから開き、左側の選択メニューでユーザー情報・Myグループ・ページ設定を切り替える。

`layout.md` の方針どおり、個人設定は別 URL にせず `/` 上でコンテンツエリアを切り替える方式で実装する
（ページタブを全画面で常に表示するため）。`layout.md` 内の「モーダル」という表記は、ダイアログ
オーバーレイを指すものではなく、この `/` 上でのコンテンツエリア切り替え方式を指す（既存実装
`PageClient.tsx` も `showSettings` の真偽で表示を排他的に切り替えているのみで、背景オーバーレイは
持たない）。

#142 では左メニューによるパネル切り替えの土台を実装する。各パネルの中身（ユーザー情報表示・編集、
Myグループ CRUD、ページ設定 CRUD）は #143〜#145 でこのプレースホルダーを置き換える。

## 機能要件

### 左の選択メニュー（#142 のスコープ）

個人設定画面の左側に固定表示される選択メニュー。3つの項目を持ち、選択中の項目に応じて右側の
コンテンツエリアの表示を切り替える。

| 項目 | アイコン | デフォルト選択 |
|---|---|---|
| ユーザー情報 | 人物アイコン | ○（個人設定を開いた直後はこれを表示） |
| Myグループ | 人物×2アイコン | - |
| ページ設定 | グリッドアイコン | - |

AIPO の個人設定メニューには上記3項目に加えて「携帯電話設定」が独立項目として存在する
（`docs/01_current/specs/home.md`）。Oripo では携帯電話番号（社内）を `turbine_user` の1フィールド
として扱い、ユーザー情報パネルの「ユーザー情報とパスワードを編集する」（要件定義書 2.6 準拠の編集
項目）に統合する。要件定義書 2.7・確定モックアップ（`個人設定ユーザー情報.png`）双方とも独立項目を
持たないため、この統合はそれらと整合している。

- メニュー上部に「個人設定」というグループ見出しを小さいグレー文字で表示する（モックアップ準拠）
- 選択中の項目はオレンジ背景・オレンジ左ボーダー・オレンジ文字（太字）でハイライトする
- 非選択の項目はグレー文字。ホバー時に薄いグレー背景を表示する
- 項目クリックでコンテンツエリアの表示のみ切り替える（URL 遷移なし、ページリロードなし）
- ヘッダーの「個人設定」タブを再度クリックしてマイページへ戻った後、再度「個人設定」タブを開くと
  選択状態はユーザー情報にリセットされる（`showSettings` が false になった時点で state を破棄するため）

### コンテンツエリア（プレースホルダー）

#143〜#145 が実装されるまでの間、選択中の項目に応じたプレースホルダーパネルを表示する。

- 各パネルはモックアップと同じヘッダー構成（アイコン + パネルタイトルを白カードの見出しに表示）を持つ
- パネル本文には「準備中」の案内文を表示する
- 将来 #143〜#145 でこのプレースホルダー本文を実データ表示・編集 UI に置き換える

### レスポンシブ対応

| ブレークポイント | 挙動 |
|---|---|
| デスクトップ（lg 以上） | 左メニュー（固定幅）+ コンテンツエリアを横並び表示（モックアップ準拠） |
| モバイル（lg 未満） | 左メニューをコンテンツ上部の横スクロール可能なピルボタン列として表示し、その下にコンテンツエリアを縦に表示する |

モバイルモックアップが存在しないため、既存のページタブ（`PageTab`）や個人設定ボタンと同様の
ピルボタン UI に合わせることで、アプリ全体の UI 一貫性を優先した（独自判断）。

## API

本 Issue（#142）では DB アクセスを伴わない（メニューの選択状態はクライアント側 state のみ）。
API は #143〜#145 でパネルごとに追加する。

---

## データモデル

本 Issue では新規テーブル・カラムは不要。選択状態は `SettingsView` の React state（`useState`）で
管理し、DB には保存しない。

## ファイル構成

```
src/app/(main)/_components/
  SettingsView.tsx       ← 個人設定画面全体（左メニュー + コンテンツエリアの状態管理）
  SettingsMenu.tsx        ← 左の選択メニュー（デスクトップ: 縦並び / モバイル: 横スクロールピル）
  settings-panels/
    UserInfoPanel.tsx     ← ユーザー情報パネル（プレースホルダー、#143 で実装）
    MyGroupPanel.tsx       ← Myグループパネル（プレースホルダー、#144 で実装）
    PageSettingsPanel.tsx  ← ページ設定パネル（プレースホルダー、#145 で実装）
```

## 受け入れ条件

- [ ] ヘッダーの「個人設定」タブをクリックすると左メニュー付きの個人設定画面が表示される
- [ ] 個人設定画面を開いた直後は「ユーザー情報」が選択された状態になっている
- [ ] 左メニューに「ユーザー情報」「Myグループ」「ページ設定」の3項目が表示される
- [ ] 選択中の項目はオレンジ背景・オレンジ左ボーダーでハイライトされる
- [ ] 「Myグループ」をクリックするとコンテンツエリアが Myグループパネルに切り替わる
- [ ] 「ページ設定」をクリックするとコンテンツエリアがページ設定パネルに切り替わる
- [ ] 各パネルにアイコン + タイトルの見出しが表示される
- [ ] ヘッダーの「個人設定」タブを閉じてマイページへ戻り、再度開くとユーザー情報が選択された状態に戻る
- [ ] モバイル（375px）で左メニューが横スクロール可能なピルボタン列として表示される
- [ ] モバイルでメニュー項目をタップするとコンテンツエリアが切り替わる
