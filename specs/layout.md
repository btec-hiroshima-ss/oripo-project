# 共通レイアウト・ヘッダー

## 概要

認証済みユーザーが利用する全ページに共通するレイアウト。
ヘッダー・ナビゲーション・コンテンツエリアを提供する。

AIPO 準拠: AIPO のヘッダー・グローバルナビゲーションに相当。

## 機能要件

### 構造

- Next.js App Router のルートグループ `(main)` で認証済みページをグループ化する
- 認証チェックは `src/middleware.ts` で処理済み（レイアウト側では不要）
- 個人設定はモーダルとして `/` 上に実装する（別 URL にしない）
  - 理由: ページタブを全画面で常に表示するため、URL を分けない設計とした

```
src/app/
  (main)/
    layout.tsx   ← 共通ラッパー（背景色のみ）
    page.tsx     ← ホーム画面（/）ヘッダー・ページタブ・ウィジェットを管理
  login/         ← 共通レイアウト適用外
```

### ヘッダー

全ページ最上部に固定表示される赤背景のバー。

**デスクトップ（lg: 1024px 以上）:**

| 領域 | 内容 |
|---|---|
| 左: ロゴ | グリッドアイコン + "Oripo" |
| 左: タブナビ | 「マイページ」「個人設定」（現在のパスに応じてアクティブ表示） |
| 右: アクション | お知らせベル + アバター（イニシャル円）+ 氏名 + 部署名 + ログアウトボタン |

**モバイル（lg 未満）:**

| 領域 | 内容 |
|---|---|
| 左 | ハンバーガーボタン（☰）+ "Oripo" ロゴ |
| 右 | お知らせベル + ユーザーアバター |

### モバイルドロワーメニュー

ハンバーガーボタンタップで左側からスライドイン表示。

- ユーザー情報（アバター + ユーザー名）
- ナビゲーションリンク: マイページ / 個人設定 / ログアウト
- オーバーレイ（背景）タップで閉じる

### レスポンシブ対応

| ブレークポイント | 挙動 |
|---|---|
| デスクトップ（lg 以上） | ヘッダー内にタブナビゲーション表示 |
| モバイル（lg 未満） | ハンバーガーメニュー。タブナビは非表示 |

## データモデル

ヘッダーに必要なセッション情報:

| 項目 | 取得元 |
|---|---|
| ユーザーID（`userId`） | iron-session（`getSession()`） |
| ログイン名（`loginName`） | iron-session（`getSession()`） |
| 氏名（`fullName`） | `getUserDetail(userId)` — DB（`turbine_user`） |
| 部署名（`department`） | `getUserDetail(userId)` — DB（`eip_m_post`）。複数所属の場合は先頭のみ表示 |

### InitialAvatar 共通コンポーネント

`src/app/(main)/_components/InitialAvatar.tsx` — ヘッダー・ユーザー名簿ウィジェット・ユーザー詳細モーダルで共用するアバターコンポーネント。

- `userId` に対応した背景色（`getIconColor`）でイニシャルを表示
- `onClick` を渡すとクリック可能になる（role=button）
- サイズは `sm`（w-7/h-7）と `lg`（w-12/h-12）の2種類

## 受け入れ条件

- [ ] 認証済み状態で全ページにヘッダーが表示される
- [ ] ロゴ（グリッドアイコン + "Oripo"）がヘッダー左側に表示される
- [ ] デスクトップでタブナビゲーション（マイページ・個人設定）が表示される
- [ ] 現在のパスに対応するタブがアクティブ表示される
- [ ] ヘッダー右側にアバター（イニシャル円）・氏名・部署名が表示される
- [ ] アバターをクリックするとユーザー情報編集モーダルが開く（実装は #140 で追加予定）
- [ ] ログアウトボタンを押すと `/login` へリダイレクトされセッションが破棄される
- [ ] モバイルでハンバーガーボタンが表示される
- [ ] ハンバーガーボタンを押すとドロワーメニューが表示される
- [ ] ドロワーのオーバーレイをタップすると閉じる
